# Presentations

This directory contains the final presentation material and selected week-by-week PDF decks from the project.

The graphs shown in the presentations are not duplicated as standalone images in `results/`. Keeping the figures inside the thesis and decks avoids clutter while still letting readers inspect the final result visually.

The directory `_source-code-map/` contains selected PYTHIA files associated with the presentation development history. It is included for provenance and is not the primary analysis source. The main reproducible analysis source is:

[../src/pythia/Pythia1.cc](../src/pythia/Pythia1.cc)
