# Presentation Source-Code Map

This folder preserves selected PYTHIA code snapshots that correspond to the development of the week-by-week presentations.

It is deliberately kept under `presentations/` so the repository front page remains focused on the final analysis. These files are useful for understanding how particular presentation-stage plots were produced, but they are not the main public analysis entry point.

Use [../../src/pythia/Pythia1.cc](../../src/pythia/Pythia1.cc) for the final thesis-level PYTHIA analysis.
